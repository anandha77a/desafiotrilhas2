# Laboratório de Química — Quiz em Dart

- **Integrantes:** Alberthy Cristhyan de Oliveira Ferraz e Anandha Helena dos santos ferreira 
- **Trilha:** MObile

## Apresentação do Quiz
**Laboratório de Química** é um jogo interativo no terminal feito em Dart. O jogador informa seu nome, responde a perguntas de múltipla escolha com feedback imediato e recebe uma avaliação final de acordo com o número de acertos.

- **Tema escolhido:** Química (elementos químicos, fórmulas, pH, ligações e gases atmosféricos).

### Exemplo de Pergunta
- **Enunciado:** Qual é o símbolo químico do elemento Ouro na Tabela Periódica?
  - A) Ag
  - B) Au *(correta)*
  - C) Fe
  - D) Pb
